# 🍓 Strawberry Pi Case

Making a Case for Strawberry Pi which is a Raspberry Pi-4 form factor STM32 development board designed as a compact computing platform.

## Overview

Curently the Straberry Pi Case is made using **Onshape** with seprate files for base and top part of it. It currently has option for attaching a 40*40*10 mm Fan on top/lid part of case.

The future expansion and changes for this would be making and add modules/add-ons for various components like screen, mic, camera, speaker, etc which can be easily attached and de-attached without screws through a slider mechanism and using magnets.

## Features:
--> A Fan Mount for Pi to keep componenets inside it cool
--> Multi side rectangular Holes for Air flow and ventilation
--> Proper holes for all ports with full accuracy
